# Module 0 — Getting Started (Operator-First)

## Goal
Give a new operator a safe, low-cost path to revenue that can **springboard** into higher-ticket services.

## The springboard concept
Start with **one service** that:
- has low equipment cost
- has repeatable SOPs
- builds reviews + proof packs
- creates upsell pathways

### Best springboard services (in your market)
**Order (your choice):**
1) **Gutter cleaning** (springboard)
2) **Traditional window cleaning**
3) **WFP + RO/DI** (upgrade path)

## Roadmap (90-day ramp)
### Phase 1 (Week 1–2): Get paid fast
- Pick 1 springboard service
- Build 1-page offer + estimate template
- Build Proof Pack habit (before/after + invisible work)
- Build review ask habit

### Phase 2 (Week 3–6): Add a second service
- Add the complementary service (windows ↔ gutters)
- Create bundle pricing

### Phase 3 (Week 7–12): Add a high-ticket service
- Roof soft wash or house wash
- Use your evidence + reviews to win at top 50–75% pricing

## “Non-negotiables” from day one
- Safety (PPE, ladder rules)
- Documentation (proof packs)
- Communication timeline
- Honest scoping (no surprises)

Each lesson ends with:

- Consumables
