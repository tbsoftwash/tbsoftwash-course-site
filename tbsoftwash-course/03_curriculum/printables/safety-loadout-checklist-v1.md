# Safety Loadout Checklist v1 (Printable)

This is the “non‑negotiable” safety loadout for Tampa Bay Soft Wash work.

**Rule:** If we touch chemicals, ladders, or traffic—this gear is part of the job.

## 1) Eye + skin
- [ ] Safety goggles (sealed or splash-rated)
- [ ] Nitrile gloves (heavy-duty)
- [ ] Long sleeves / skin coverage options

## 2) Respiratory
- [ ] Respirator (appropriate cartridges for the products in use)

## 3) First aid + wash
- [ ] First aid kit
- [ ] Eyewash bottle or eyewash station

## 4) Fire + site safety
- [ ] Fire extinguisher
- [ ] Safety cones / high-visibility markers (when working near driveways/roads)
- [ ] Ladder stabilizer(s) / standoff (when applicable)

## 5) Chemical discipline (minimum)
- [ ] Labels readable
- [ ] Secondary containment / tote discipline (as applicable)
- [ ] Dedicated rinse water available
- [ ] Backup pump-up sprayer (working) + dedicated sprayers labeled by lane

## 6) Documentation
- [ ] Phone charged
- [ ] Proof Pack shots captured

## Notes
This checklist is **not** a substitute for SDS, labels, and local regulations.
