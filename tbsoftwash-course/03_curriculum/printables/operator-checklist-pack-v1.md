# Operator Checklist Pack v1 (Printable)

Print this and keep it in the truck.

---

## Roof Soft Wash — QA Checklist

### Before you start
- [ ] Roof type confirmed (shingle/tile/metal)
- [ ] Scope confirmed (roof only vs bundles)
- [ ] Pre-existing damage documented (photos)
- [ ] Wind direction checked
- [ ] Plant protection started (pre-wet)
- [ ] Dedicated rinse line staged

### During
- [ ] Work in sections (controlled coverage)
- [ ] Plants rinsed throughout
- [ ] Overspray monitored (windows/paint/screens)

### Rinse / finish
- [ ] Rinse complete (low pressure)
- [ ] Gutters/downspouts rinsed
- [ ] Final plant rinse
- [ ] Walkways not slick

### Proof Pack
- [ ] Before/after angles matched
- [ ] Close-up wins captured
- [ ] Exceptions documented
- [ ] Proof Pack link stored in CRM/job board

### Customer closeout
- [ ] Completion message sent
- [ ] Expectations set (if any slow-release improvement)

## House Wash — QA Checklist

### Before
- [ ] Scope confirmed (walls/soffits/trim)
- [ ] Oxidation vs organic diagnosed
- [ ] Pre-existing conditions photographed
- [ ] Plants pre-wet
- [ ] Wind checked
- [ ] Dedicated rinse line staged

### During
- [ ] Top-down workflow
- [ ] Even application (no striping)
- [ ] Avoid vents/soffit gaps/failing seals
- [ ] Plants rinsed during dwell

### Rinse / finish
- [ ] Thorough rinse
- [ ] Windows/doors/fixtures checked for residue
- [ ] Final plant rinse

### Proof Pack
- [ ] Before/after angles matched
- [ ] Exceptions documented (oxidation, hard water, rust)
- [ ] Proof Pack link logged

### Customer closeout
- [ ] Completion message sent
- [ ] Expectations set for anything outside scope

## Flatwork — QA Checklist

### Before
- [ ] Substrate identified (concrete/pavers/coated/stone)
- [ ] Pre-existing damage photographed
- [ ] Runoff plan set
- [ ] Plants pre-wet

### During
- [ ] Consistent overlap passes
- [ ] Steady walking speed
- [ ] No lingering in one spot
- [ ] Edges handled carefully

### Finish
- [ ] Wide-angle check for striping
- [ ] Edges clean
- [ ] No overspray on walls/doors

### Proof Pack
- [ ] Before/after consistent angles
- [ ] Notes on permanent stains
- [ ] Link logged

## Final Walk Checklist (Universal)

### 1) Safety + site
- [ ] Hoses, tools, ladders cleared
- [ ] Walkways not slick
- [ ] Gates closed (if applicable)

### 2) Landscaping
- [ ] Final rinse completed
- [ ] No concentrated runoff damage zones

### 3) Glass + fixtures
- [ ] Glass check: no residue/spotting
- [ ] Fixtures check: no residue on lights/cameras/door hardware

### 4) Runoff
- [ ] No dirty runoff pushed into beds
- [ ] Edges/transitions rinsed

### 5) Proof Pack
- [ ] Before/after angles matched
- [ ] Exceptions documented
- [ ] Proof Pack link uploaded and logged

### 6) Customer closeout
- [ ] Completion message sent
- [ ] Expectations set (if any limitations)
- [ ] Review ask scheduled (24–72 hours)

## Proof Pack — Minimum Shot List

### Universal (all jobs)
1) Context shot (house number / identifiable context). Avoid people + plates.
2) Wide BEFORE (full area)
3) 2–6 close-up BEFORE shots (problem areas)
4) Wide AFTER (same framing)
5) Close-up AFTER (match each close-up)
6) Final “jobsite clean” shot (hoses coiled, area tidy)

### Roof add-ons
- Multiple roof planes + valleys
- “Worst side” (often shaded/north)
- Drip edge/gutter line

### Windows add-ons
- Exterior reflection check (2 angles)
- Frames/sills/tracks (if included)

### Gutters / brightening add-ons
- Tiger stripe close-up before/after
- Downspout discharge (if relevant)

### Flatwork add-ons
- Wide “striping-free” after
- Edges/transitions
