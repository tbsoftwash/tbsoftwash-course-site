# Module 5 — Windows: Traditional Workflow + QC (Lesson)

## What you’re doing today
You’re learning the traditional window workflow that produces consistent, premium results.

If you can’t make traditional perfect, WFP won’t save you.

## Why this matters
Traditional is the most controllable method.

It’s also where customers notice the smallest defects.

## Tools & materials (minimum viable)
- Bucket + mop/scrubber
- Squeegee + fresh rubber
- Several clean lint-free towels
- Scraper/razor (optional, only when appropriate)
- Toolbelt (optional but helps speed)

## Quick Start (the 30-second version)
1) Prep
2) Scrub
3) Squeegee
4) Detail edges
5) Sunlight/reflection check

VIDEO: https://www.youtube.com/watch?v=iSwdT4MdZsM | Quick traditional window clip (short). Focus: clean edges + no streaks.

## Step-by-step workflow (foreman sequence)
1) Prep
   - stage towels
   - check screens (don’t drip dirty water onto clean glass)
2) Scrub
   - even coverage
3) Squeegee
   - consistent pulls
   - keep rubber clean
4) Detail edges
   - corners/top edges matter
5) Final QC
   - check from at least two angles
   - do a “sunlight/reflection” pass

## Decision points
- If glass has stuck debris:
  - scraper only if safe/appropriate, fresh blade, correct technique.

- If frames are oxidized:
  - set expectations; avoid dragging oxidation onto glass.

## Common mistakes + fixes
- Old rubber
  - Fix: replace often.
- Dirty towels
  - Fix: clean towel policy.
- Over-soaping
  - Fix: less soap, better technique.
- Rushing corners
  - Fix: slow down at edges.

## What good looks like
- No edge lines.
- No runs on sills.
- Clean from inside view.

## How to prove it (Proof Pack)
- reflection photo at an angle (shows streaks)
- before/after of the worst window
