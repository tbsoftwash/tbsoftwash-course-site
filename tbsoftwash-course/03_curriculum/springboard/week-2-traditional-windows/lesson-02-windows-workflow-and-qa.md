# Week 2 — Traditional Windows: Workflow + QA (Lesson)

## The workflow
1) Confirm scope (inside/out, screens, tracks)
2) Protect interiors (drop cloths)
3) Dry prep frames/sills
4) Wash + squeegee
5) Edge detail
6) Drip check
7) Add-ons (screens/tracks) if sold

## QA checks
- sunlight streak check
- no drips on sills/floors
- customer walk-by approval if present
