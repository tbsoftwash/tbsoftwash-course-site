# Chemical Index (Comprehensive, Operator-Focused)

## Purpose
Create a single source of truth for the chemicals used in exterior cleaning, including:
- what each chemical is used for
- where it is safe vs unsafe
- mixing *ranges* and decision logic (not reckless recipes)
- PPE + storage + transport
- neutralization + runoff considerations
