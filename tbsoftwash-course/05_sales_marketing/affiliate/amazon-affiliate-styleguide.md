# Amazon Affiliate Style Guide (Course + Website)

## Goal
Promote Amazon products throughout the course in a way that is:
- helpful (operator-first)
- scalable (templates)
- compliant (Associates disclosure + no-price rules)
- trust-preserving (no spam, no fake urgency)

## Placement rules
- Prefer **end-of-lesson “Gear Box”** blocks over sprinkling links in every paragraph.
- Cover **everything reasonable**: operator gear + homeowner-safe items + admin/marketing ops tools, as long as it’s helpful and not spammy.
- Use **Starter / Pro / Premium** tiers.
- Always include: *why this item matters* + *common failure mode if you cheap out*.
- Safety note: do not encourage unsafe DIY roof work; homeowner gear should focus on prep, protection, and evaluation.

## Link rules (compliance-friendly)
- Do **not** include specific prices (they change). Use phrases like “budget-friendly” / “mid-tier” / “premium.”
- Do **not** copy/paste Amazon review text.
- Use your Amazon Associates links exactly as generated.

## Disclosure (must appear near links)
Use one of these lines near any Gear Box section:
- "As an Amazon Associate, we earn from qualifying purchases."
- "Some links are affiliate links. As an Amazon Associate we earn from qualifying purchases."

Also maintain a site-wide disclosure page (recommended): `/disclosure/`.
