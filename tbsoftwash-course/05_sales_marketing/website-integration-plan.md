# Website Integration Plan (tbsoftwash.com)

Goal: incorporate the free course into tbsoftwash.com in a way that:
- increases leads and close rate
- strengthens premium positioning (top 50–75% pricing)
- improves SEO topical authority
- creates trust via proof + education

## Integration model (recommended)
### 1) Create a dedicated hub
**URL:** `/academy/` or `/resources/` (pick one; “academy” feels premium)
Contains:
- Course landing page (what it is, who it’s for, what’s inside)
- Module index page
- Download library (checklists)

### 2) Make the course a trust layer, not a distraction
Primary service pages still convert. The course supports them by:
- answering objections
- showing process
- demonstrating safety/skill

Place “Learn our process” sections on:
- Roof cleaning
- House washing
- Window cleaning
- Gutters
- Flatwork

Each links into the relevant academy module.

### 3) Course-as-lead-magnet (soft gate)
Because you’re giving it away free, use a **soft gate**:
- Option A: Email capture (recommended): “Send me the course + checklists”
- Option B: No gate, but strong CTAs throughout

If email capture:
- deliver PDF checklists
- nurture with 3–5 email sequence (education + proof + CTA)

## Page types to build (site architecture)
1) **Course landing page**
- Value proposition
- What’s included (modules)
- Who it’s for (homeowners + DIYers + curious)
- Why it matters (roof warranty, plant safety, etc.)
- CTA: Request estimate

2) **Module pages** (SEO-friendly)
Example:
- `/academy/roof-cleaning/`
- `/academy/house-washing/`
- `/academy/gutter-brightening/`

Each includes:
- overview
- common mistakes
- what TBSoftWash does differently
- proof pack examples
- FAQ
- CTA to estimate

3) **Download pages**
- “Roof soft wash prep checklist”
- “How to choose a legit contractor”
- “Before/after photo checklist”

## SEO + schema recommendations
- Use FAQ sections (FAQPage schema)
- Add HowTo schema where appropriate (but don’t publish dangerous chemical ratios)
- Internal linking: service pages ↔ academy pages ↔ blog posts

## Content policy (important)
- Publish **ranges and safety**, not precise chemical recipes.
- Teach homeowners what to look for:
  - licensing/insurance proof
  - pre-wet plant protection
  - documentation/Proof Pack
  - method selection by substrate

## Conversion integration (where CTAs live)
- Sticky “Request a Free Estimate” on academy pages
- “See pricing” link to `/pricing/`
- “See proof” link to gallery/reviews

## Implementation steps
1) Choose hub slug: `/academy/` or `/resources/`
2) Create course landing page + 5 module pages for core services
3) Add “Learn our process” blocks to each service page
4) Add downloadable checklists (PDF)
5) Add simple email capture + automation (optional)

## Metrics to track
- academy page traffic → estimate form conversion
- time on page
- assisted conversions (academy visited before contact)
- keyword growth for ‘soft wash roof cleaning’, ‘gutter brightening’, etc.
