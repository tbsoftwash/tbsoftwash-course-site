# TBSoftWash Course Build

This folder contains the working scope, research, curriculum, and assets for the comprehensive exterior cleaning course based on tbsoftwash.com.

## Structure
- `00_scope/` – goals, audience, outcomes, constraints
- `01_business_profile/` – extracted site notes + positioning
- `02_competitors/` – Florida competitor research + takeaways
- `03_curriculum/` – module map, lessons, worksheets
- `04_sops/` – field SOPs, checklists, QA
- `05_sales_marketing/` – offers, pricing logic, scripts, ads
- `06_ops/` – hiring, training, dispatch, CRM, reviews
- `07_assets/` – screenshots, images, diagrams
- `99_backlog/` – open questions + next steps
