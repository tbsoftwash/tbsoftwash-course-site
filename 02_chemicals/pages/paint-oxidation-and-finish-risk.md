# Painted Surfaces + Oxidation + Finish Risk (Operator)

## Category
Painted surfaces can look “dirty” when they’re actually oxidized.

Oxidation is not mildew.

## The risk
If you promise oxidation removal inside a standard wash:
- you create callbacks
- you create bad reviews

## Operator rules
- Diagnose before you spray.
- Set expectations.
- Test spot for any restoration work.

## Customer language
- “We can remove organic growth safely. Oxidation is a different issue — we’ll tell you what’s realistic before we start.”
