# Windows (Homeowner Lane): Hard Water vs Etching vs Seal Failure

## Why this matters
Not all “spots” are the same.

If we diagnose wrong, expectations break.

## Hard water / mineral staining (often removable)
Common signs:
- spots/rings on the *outside* surface
- worse in sprinkler zones
- improves with proper stain treatment

## Etching (sometimes permanent)
Common signs:
- looks like staining but doesn’t improve much
- visible from multiple angles
- may be damage to the surface

## Seal failure (fogging between panes)
Common signs:
- haze between panes
- changes with temperature/humidity

## The honest truth
We can clean glass.

We can’t always restore damaged glass.

## What we do
- test spot
- set expectations
- recommend restoration only when it makes sense
- document exceptions
