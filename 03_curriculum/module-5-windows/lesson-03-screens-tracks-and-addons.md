# Module 5 — Windows: Screens, Tracks + High-Value Add-ons (Lesson)

## The rule
If you clean glass but leave dirty screens and tracks, the customer feels like you skipped the job.

## Screen cleaning (the cleanest sequence)
- Remove screens (when included)
- Clean/rinse screens away from clean glass
- Let screens drain/dry before reinstall when possible

## Track detailing (expectation setting)
Track detailing is labor.

It should be a separate line item or clearly defined scope.
