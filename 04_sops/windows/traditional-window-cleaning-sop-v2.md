# Traditional Window Cleaning SOP v2 (Inside/Out) (Springboard)

## Service
Traditional window cleaning (washer + squeegee) for interior/exterior glass, with optional add-ons (screens, tracks).

> Operator principle: This is a **detail** service. The product is “no drips + no streaks + respect for the home.”

## Goal (definition of done)
- Streak-free glass (sunlight check).
- Frames/sills cleaned to scope.
- No drips inside; floors protected.
- Proof Pack complete (where privacy allows).

## Safety / PPE
- Shoe covers or clean shoes for interior work.
- Drop cloths in interior zones.
- Ladder safety if needed for exterior.

## Pre-checks (arrival)
1) Confirm scope:
   - inside/out?
   - screens included?
   - tracks included?
   - hard water spots excluded?
2) Identify risk windows:
   - old tint film
   - scratched glass
   - tempered vs delicate panes
3) Proof Pack BEFORE (privacy-safe):
   - wide exterior reflections
   - obvious problem panes

## Tools / equipment
- Washer/mop + squeegee
- Detail towel/microfibers
- Bucket + solution
- Scraper (only when safe; never dry scrape)
- Drop cloths (interior)
- Screen tools (if included)

## Step-by-step workflow
1) **Protect + stage**
   - Drop cloths, corner towels.
   - Confirm which windows are being done.

2) **Dry prep**
   - Remove dust/debris from frames/sills to prevent mud.

3) **Wash + squeegee**
   - Consistent technique.
   - Detail edges.

4) **Frames/sills**
   - Wipe to scope.

5) **Interior drip check**
   - Final walk-through with microfiber.

6) **Screens/tracks (if sold)**
   - Clean per add-on SOP (to be expanded).

7) **Proof Pack AFTER + completion**
   - Reflection check photo where possible.
   - Send completion message + link.

## Quality checks (QA)
- Sunlight angle check for streaks.
- No drips on sills/floors.
- Customer “walk-by” approval if present.

## Common failure modes
- Edge haze/streaks → prevention: edge detailing discipline.
- Interior drips → prevention: towel placement + final drip check.

## Customer communication
- Set expectations for hard-water spotting vs normal soil.
- Offer maintenance cadence options.
