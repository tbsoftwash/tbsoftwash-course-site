# RO/DI System Build SOP v1 (WFP Window Cleaning)

## Service
Build a basic RO/DI water purification setup for water-fed pole window cleaning.

> Operator principle: Purified water is a performance tool. If you can’t measure it (TDS), you can’t manage it.

## Goal (definition of done)
- RO/DI system assembled with correct flow path.
- No leaks under pressure.
- Carbon stage protects RO membranes.
- DI stage produces low-TDS water for spot-free results.
- Operator can test TDS and knows when to service resin.

## Safety
- Use potable-water-safe components where applicable.
- Depressurize before opening housings.
- Keep hoses tidy; avoid trip hazards.

## System flow (from our diagram)
Water spigot → carbon filter → RO membrane (stage 1) → rejection valve (waste control) → RO membrane (stage 2) → DI tank → water fed pole

> Note: Some systems run RO stages in series; confirm your exact design. This SOP assumes the flow above.

## Parts categories (build the list before you buy)
- Pre-filter / carbon stage housing + cartridges
- RO membrane housing(s) + membrane(s)
- Waste/rejection valve + tubing
- DI vessel + resin
- Fittings/tubing (standardize sizes)
- Mounting board/cart (optional)
- TDS meter

## Build steps (high level)
1) **Layout & mounting**
   - Decide: board mount vs cart.
   - Keep housings accessible for service.

2) **Plumbing**
   - Build in correct order.
   - Use consistent fittings; label lines (IN / OUT / WASTE).

3) **Leak check**
   - Pressurize slowly.
   - Inspect every fitting.

4) **Flush & startup**
   - Flush carbon stage.
   - Follow membrane flush guidance.

5) **TDS testing routine**
   - Test source water.
   - Test after RO.
   - Test after DI.

## Operating routine (field)
- Check TDS before starting a window job.
- If spotting occurs, re-check TDS and technique.

## Service / maintenance
- Carbon: replace per usage and chlorine exposure.
- RO membrane: replace per performance decline.
- DI resin: replace when output TDS rises above your acceptable threshold.

## Storage
- Drain and store out of sun.
- Protect from freezing.
